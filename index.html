WHY THERE IS NO ".EXE" BUTTON

A browser tab cannot compile a program. Making an .exe needs a linker, an .apk needs the Android SDK, and an .ipa needs a Mac and Apple's signature. No engine does it from inside a browser — Godot, Unity and GameMaker all run a compiler on your own computer.

So the two kits above give you the finished project those compilers expect, with the commands written out in a BUILD.txt. Unzip, type two lines, and you have the real thing.

Xbox and PlayStation are further off again: both need a registered developer account, a devkit machine you apply for, and a signed licence agreement before Microsoft or Sony will let anything run. That is not something an engine can hand out — but the desktop kit is the same code those ports start from.
