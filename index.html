How

Left-click paints the chosen sprite as a tile.
Right-click erases.

Show a room from code:
room(2)

Ten little steps

Press Try it on a step: the code jumps into the editor and runs. Change a number, run it again, see what happens. That's the whole job.

Every command

show(1)              show sprite 1
hide(1)              hide sprite 1
move(1, 10, 0)       move sprite 1 by 10 pixels right, 0 down
put(1, 100, 50)      put sprite 1 exactly at x=100 y=50
print("Hi", 0, 0)    draw text at x=0 y=0
room(2)             show room 2 behind everything
set(score, 0)       make a variable
add(score, 1)       add to a variable
wait(30)            wait 30 frames (about half a second)
sound(1)            make a beep — try 1 to 6
settile(80, 64, 0)  change the room tile at that spot (0 = rub it out)
stop()              stop the program

Blocks (a block ends with end):

when start            runs one time at the beginning
  show(1)
end

when key left         runs while the left arrow is held
  move(1, -2, 0)                keys: left right up down space z x
end

every frame           runs 60 times a second
  print("score: ", 4, 4)
end

repeat 5              do something 5 times
  move(1, 4, 0)
end

if touching(1, 2)      true when sprite 1 overlaps sprite 2
  hide(2)
end

if x(1) > 300          x(1) and y(1) are a sprite's position
  put(1, 0, y(1))
end

if free(1, -2, 0)      true when sprite 1 can move that way
  move(1, -2, 0)              without bumping into a room tile
end

Things you can ask about:

x(1)  y(1)           where a sprite is
visible(1)          is it shown?
touching(1, 2)      are two sprites overlapping?
free(1, dx, dy)     can it move there? (walls)
tile(80, 64)        which sprite is painted at that spot
random(10)          a surprise number from 0 to 9
key(space)          is a key held down right now?

Notes
· The screen is 320 x 240 pixels. x grows right, y grows down.
· Sprites are 16 x 16. Sprite numbers start at 1 and never run out.
· Anything after # is a comment.
· Variables can be used anywhere a number can: move(1, speed, 0)
